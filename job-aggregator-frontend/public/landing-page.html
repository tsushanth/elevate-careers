🍎 macOS Users: First-Time Setup

When you first open Job Tracker, macOS may show a security warning. This is normal for apps distributed outside the Mac App Store.

Quick Fix (30 seconds):

  1. Download and locate Job Tracker.app
  2. Right-click (or Control + click) on the app
  3. Select "Open" from the menu
  4. Click "Open" again in the confirmation dialog

This is a one-time step. The app will open normally after that.

Alternative: Using System Settings
  1. Try to open Job Tracker (double-click)
  2. When blocked, go to System Settings → Privacy & Security
  3. Scroll to "Security" and click "Open Anyway"
  4. Enter your password and click "Open"
Why do I see this warning?

Job Tracker is currently in beta and doesn't yet have Apple's notarization (requires $99/year Developer account). This is a standard macOS security feature for unsigned apps.

Is it safe? Absolutely! You can verify the source code on our GitHub repository.

We're working on obtaining full Apple code signing for future releases.
